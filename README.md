## ⚡ Features
- 🚀 **Dynamic Dot Text Animations** (`.han`, `.kaise ho`, etc. with 5s moving transitions)
- ✨ **Animated Dynamic Greetings** (`.hello`, `.hii`, `.gm`, `.gn`)
- 🛡️ **SQLite Auto-Lock Recovery**
- ⚡ **Lightweight & High-Speed**
